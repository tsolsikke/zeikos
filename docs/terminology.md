# 用語と書き方

ZeikOSのコミットメッセージ、ドキュメント、ADR、コードコメント、報告での、用語の選び方である。

## 決まり

- IT用語は、無理に和語へ言い換えない。一般的なIT用語（カタカナ語・英語の用語）を、そのまま使う（運用者の決定。2026-10-08）。
- 文章そのものは、これまでどおり、柔らかく分かりやすい自然な日本語で書く（`CLAUDE.md`の「コミットメッセージ」）。
- コードの名前（関数・型・featureの名前）が英語の用語なら、文章でもその言い方に合わせる（例: `excursion stack`、`quarantine`）。
- 既存のドキュメントとコメントは、一括では書き換えない。新しく書くものと、別の理由で触った箇所だけを、この書き方にする（一括の書き換えは、別の課題で行う）。
- そのため、しばらくは古い言い方と新しい言い方が混ざる。下の対応表で読み替える。
- 名前で参照されている見出しは、触るときも変えない（変えるなら、参照している側も同じコミットで直す。`CLAUDE.md`の「エージェント向け設定ファイルの扱い」）。
- 課題キーの位置や、コミットメッセージの行数など、ほかの決まりは変わらない。
