# 0082. 写像の表を置き、無名の`mmap`・`munmap`・`mprotect`をLinuxの形で受ける

## Status

Accepted（2026-10-06に運用者が設計案を承認し、同じ日に4つの刻みで実装した）。

## Date

2026-10-06

## Context

- 目指す先は、muslで静的リンクしたLinuxのプログラムをそのまま動かすことである（`ADR-0074`）。muslの`malloc`は、`brk`の先頭に見張り（`PROT_NONE`の`MAP_FIXED`）を置き、大きな確保を無名の`mmap`で取り、要らなくなった範囲の一部を`munmap`で返す。Rustの`std`は、スレッドの見張りのページを`mprotect(PROT_NONE)`で作る。
- このカーネルの`mmap`は、共有メモリと画面をfdから写すだけだった。配った番地は、一方向に伸びるカウンタで覚えていて、どこに何が写っているかを知らず、`munmap`も`mprotect`も無かった。
- プロセスは1つのCPUに留まる（`Task::owner`。コア間の移動は無い）。スレッドはまだ無い。

## Decision

### 1. プロセスごとに写像の表を持ち、`mmap`が配る範囲を表で覚える

- 表（`kernel/src/mappings.rs`の`MemoryMap`）は64欄で、1欄が`[start, end)`・種類・書けるか・写してあるか、を持つ。種類は、無名・共有メモリ・画面（`mmap`が配る）と、像・スタック・見張りのページ・ヒープ（載せる側と`brk`が登録する）。
- 空いた所を使い直す（first-fit）。以前のカウンタは、外した範囲を使い直せなかった。
- 表は、スロットと遠征の深さごとの静的な置き場に置く（`ADR-0081`の2と同じ理由。載せる経路の遠征スタックの枠を太らせない）。
- 像・スタック・見張りのページ・ヒープも表に載せる。そこへは`MAP_FIXED`で置けず（`-EINVAL`）、`munmap`もできず、`brk`は無名の写像へ伸びない（`-ENOMEM`）。
- 純粋な論理（置く・外す・分ける・権限を変える）はホストの試験で確かめる。

### 2. 無名の`mmap`は、ゼロのフレームをその場で写す。`PROT_NONE`は範囲だけを覚える

- `MAP_ANONYMOUS`で、`PROT_READ`か`PROT_WRITE`が在れば、ページごとにフレームを取り、0で埋めて写す（遅延の割り当て——触ったときに写す形——は採らない。下の案1）。1回の上限は16MiB（`docs/deferred-decisions.md`）。
- `PROT_NONE`は、表に範囲だけを覚え、葉は作らない。触ればページフォルトで、プロセスが終わる。
- `PROT_EXEC`は`-EPERM`——書ける形と実行できる形を同時に許さない（W^X。`ADR-0071`。JITは目指さない）。
- `MAP_FIXED`は、重なる無名の写像とヒープのページを外してから置く。`MAP_FIXED_NOREPLACE`は、重なれば`-EEXIST`。番地を指定する形は無名の写像だけで、fdつきは`-EINVAL`（`docs/deferred-decisions.md`）。

### 3. `munmap`は範囲の一部も受け、残る部分を分けて表に戻す。外したフレームはその場でアロケータへ返す

- 範囲に掛かる無名の写像を外し、前と後ろに残る部分を分けて表に戻す。像・スタック・見張りのページ・ヒープ・共有メモリ・画面に掛かれば、何も変えずに`-EINVAL`。共有メモリと画面の`munmap`は、`ADR-0065`の往復と合わせて別に決める（`docs/deferred-decisions.md`）。
- 外したフレームは、空間の破棄が通す検疫（TLBの世代。`ADR-0027`）を通さず、その場でアロケータへ返す。TLBは、このCPUの分だけを`invlpg`で落とす。**プロセスが1つのCPUに留まることに頼っている**——スレッド（M3a）が入り、同じ空間を複数のCPUが同時に使う形になった時点で、この前提は崩れる。ほかのCPUのTLBに古い写像が残り、返したフレームを別の持ち主が使った後に、そのCPUから古い番地で触れてしまう。そのときは検疫と同じ道へ寄せ、ほかのCPUへIPIで落とさせる（`docs/deferred-decisions.md`の「TLBシュートダウンと検疫」）。
- `brk`が縮むときの返し方（その場でアロケータへ）と同じ道である。

### 4. `mprotect`は葉の`P`と`W`を書き換える。`PROT_NONE`はフレームを持ったまま葉を外す

- 範囲の全部が写像で覆われていなければ`-ENOMEM`（Linuxと同じ）。変えてよい種類は、無名・ヒープ・像・スタック。見張りのページ・共有メモリ・画面は`-EINVAL`。
- `PROT_NONE`: 葉の`P`と`W`を落とし、ソフトウェア用の空きビット10（`PTE_RETAINED`）を立てて「フレームは残っている」を覚える。読める形へ戻すと同じ中身が戻る。`munmap`と空間の破棄は、この印の葉からもフレームを返す（返さないと漏れる）。
- 初めから写していなかった無名の写像（`mmap(PROT_NONE)`）を読める形にするときは、その時点で0のフレームを写す。像・スタック・ヒープは写していないページを持たないので、そこで写していないページに当たれば`-ENOMEM`。
- **W^X。** `PROT_EXEC`は`-EPERM`。**実行できるページ（`NX`が0）を書ける形にする求めも`-EPERM`**——範囲の一部でも在れば、表を変える前に見て、何も変えずに断る。`PROT_EXEC`を付けない`mprotect`は、ページを実行できない形にする（`NX`を立てる。Linuxと同じ。実行を外す向きだけを許す）。像の実行できる区画の権限を`mprotect`で変える道は、実行を外す向きしか無い。
- 変えた葉のTLBは、このCPUの分だけを`invlpg`で落とす（上の3と同じ前提）。
- ページテーブルを読む側のうち、ユーザーの番地の検証（`walk_page_table`）は、印の葉を「写していない」と見る——ユーザーポインタとしては触れない番地なので正しい。権限の一覧（`page-perms`）には、印の葉は行に出ない（`docs/deferred-decisions.md`）。

## Alternatives Considered

1. **無名の`mmap`を遅延の割り当てにする（触ったときにページフォルトで写す）**: 採らない。ページフォルトのハンドラがフレームを取る道を作ることになり、アロケータの借り方と検疫の設計に手が入る。musl・Rustの`std`は、取った範囲をすぐ使うので、今は差が出ない。大きな範囲をまばらに使う利用者が出たら考える。
2. **`munmap`で外したフレームを検疫に入れる**: 今は採らない。検疫は空間の破棄の単位で動いていて、プロセスの途中で入れる口が無い。プロセスが1つのCPUに留まる間は、その場で返して正しい（上の3）。スレッドを入れるときに、こちらへ寄せる。
3. **`PROT_NONE`で葉を外してフレームを返し、戻すときに0のページを写す**: 採らない。Linuxでは`PROT_NONE`にしても中身が残る（`mprotect`は保護を変えるだけで、中身を捨てない）。muslの`malloc`やガベージコレクタは、この性質に頼る。
4. **`PROT_NONE`の印を、別の表（番地の一覧）で持つ**: 採らない。葉の空きビットなら、`munmap`と破棄が葉を読む所で一緒に見られる。共有メモリの印（ビット9。`ADR-0065`）と同じ形である。
5. **実行できるページへの`PROT_WRITE`を、`PROT_EXEC`の指定が無いなら許す（実行を外しつつ書ける形にする）**: 採らない。Linuxはそれを通すが、像のコードの区画を書ける形にする求めは、このカーネルでは誤りか攻撃の形しか無い。断って名指しする（運用者の決定。2026-10-06）。
6. **写像の表を`UserProcess`に足す**: 採らない（上の1。遠征スタックの余りのため）。

## Consequences

- muslの`malloc`の見張りの流れ（`brk`、先頭への`PROT_NONE`の`MAP_FIXED`、`brk`を戻す、`munmap`）と、Rustの`std`の見張りのページ（`mprotect(PROT_NONE)`）が通る。
- `syscall-test`に検算を18本足した（95から112）。書けなくしたページへ書くプログラム（`/bin/mprotect-ro`）と、自分のコードのページを実行できない形にするプログラム（`/bin/mprotect-nx`）を`spawn`で起こし、どちらも「畳まれた・ベクタ14」で終わることを見る。
- 破壊テストを6つ足した（`docs/verification-coverage.md`の「写像の表と`mprotect`」）。
- 遠征スタックの使用量は増えていない（実測。`syscall-test` 32,264、`zash` 32,440。表は静的な置き場に在る）。`UserProcess`は、`mmap`の3欄が表へ移った分、小さくなった。
- 静的な置き場が、表の分（4欄で6,304バイト。実測）増えた。
- `user-mmap:`の行に、プロセスの終わりに表に残っていた写像の数と無名のページの数が出る。`mmap`で取って返さないプログラムが見える。
- 外したフレームをその場で返す形は、スレッドが入ると崩れる（上の3）。持ち越しに書き、スレッドの課題の前提にする。
- 権限の一覧（`page-perms`）には、`PROT_NONE`にした葉が出ない。一覧で見たいなら、印の葉を読む形を足す（`docs/deferred-decisions.md`）。
